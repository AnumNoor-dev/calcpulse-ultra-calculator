## ✨ Key Upgrades & Features
- **Multi-Mode Engine:** Switch between Standard, Scientific, and Financial EMI Loan calculation suites.
- **Financial EMI Analytics:** Real-time monthly EMI and total interest payback breakdown.
- **Tape History Log:** Dynamic calculation log drawer with click-to-reuse values.
- **Ultra-Neon Cyber UI:** Custom neon gradient controls, glassmorphic container elements, and high-contrast OLED screen styling.
